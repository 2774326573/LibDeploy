# LibDeploy — 可执行文件依赖分析与打包工具

## 一、项目概述

LibDeploy 是一款面向 Windows 平台的桌面工具，用于分析可执行文件（.exe / .dll）的动态链接库依赖，自动定位缺失的依赖项，将其复制到目标目录，并支持一键打包或生成安装程序。

目标用户：需要部署 C/C++/Qt/wxWidgets 项目的开发者，替代手动跑 Dependency Walker 再手动拷 dll 的繁琐流程。

## 二、功能列表

### 2.1 核心功能

| 功能 | 说明 |
|------|------|
| 依赖分析 | 解析 PE 导入表，递归枚举所有直接/间接依赖的 DLL |
| 缺失检测 | 对比系统路径与应用目录，标出缺失的 DLL |
| 依赖定位 | 在用户指定的搜索路径中查找缺失 DLL |
| 一键复制 | 将找到的 DLL 复制到可执行文件所在目录 |
| 打包导出 | 将可执行文件 + 所有依赖打包为 ZIP |
| 安装程序生成 | 生成 NSIS 或 Inno Setup 脚本并调用编译 |

### 2.2 辅助功能

- 搜索路径管理（添加/移除/排序）
- DLL 分类过滤（见第五节，三层分类而非简单排除）
- 依赖树可视化（树形控件展示层级关系，按类别着色）
- MSVC 运行时检测与一键捆绑（自动识别所需 VC++ Redistributable 版本）
- 目标系统版本选择（Windows 7 / 8.1 / 10 / 11，影响哪些 DLL 必须随包）
- 日志面板（记录每步操作与结果）
- 配置持久化（JSON 保存上次的搜索路径、分类规则等）

## 五、DLL 分类体系（核心设计）

### 5.1 三层分类

不同 Windows 版本预装的 DLL 不同，简单粗暴地"排除所有系统 DLL"会导致在旧系统或精简版系统上运行失败。
因此将 DLL 分为三类，由内置数据库 + 运行时检测共同决定：

| 类别 | 说明 | 部署策略 |
| --- | --- | --- |
| **OsCore**（OS 核心） | 所有 Windows 版本必然存在，不可能缺失 | 安全跳过，不需打包 |
| **Redistributable**（可再发行） | 由 VC++/DirectX/UCRT 运行时提供，旧系统可能没有 | 必须打包 DLL 或捆绑 Redist 安装包 |
| **ThirdParty**（第三方） | Qt、wxWidgets、用户自己的 DLL 等 | 必须打包 |

### 5.2 OsCore 白名单（仅列举，完整表内置于代码）

这些 DLL 在 Windows 7 SP1 及以上所有版本均存在，永远不需要打包：

```
kernel32.dll   ntdll.dll      user32.dll     gdi32.dll
advapi32.dll   shell32.dll    ole32.dll      oleaut32.dll
ws2_32.dll     rpcrt4.dll     comctl32.dll   comdlg32.dll
imm32.dll      winmm.dll      winspool.drv   shlwapi.dll
setupapi.dll   cfgmgr32.dll   msimg32.dll    opengl32.dll
```

> **注意**：`msvcrt.dll`（MSVC 旧版 CRT）虽然是系统文件，但建议不依赖它，编译时应链接静态 CRT 或现代 UCRT。

### 5.3 Redistributable 分类规则

| DLL 名前缀/模式 | 来源 | 最低 Windows 版本 |
|----------------|------|-------------------|
| `vcruntime140*.dll`, `msvcp140*.dll`, `concrt140.dll` | VS2015-2022 VC++ Redist | 无（需手动安装） |
| `vcruntime120*.dll`, `msvcp120*.dll` | VS2013 Redist | 无 |
| `ucrtbase.dll`, `api-ms-win-crt-*.dll` | Universal CRT | Win10 内置；Win7/8.1 需 KB2999226 |
| `d3d9.dll`, `d3d11.dll`, `dxgi.dll` | DirectX / WDDM 驱动 | Win7+ 基本有，但版本可能旧 |
| `d3dcompiler_4?.dll` | DirectX Shader Compiler | 需随包 |
| `api-ms-win-downlevel-*.dll` | AppCompat Shim | Win8.1 以下需要 |
| `mfplat.dll`, `mf.dll` | Media Foundation | 需 Media Feature Pack（N 版系统无） |

### 5.4 API Set DLL 的处理

`api-ms-win-*.dll` 是 Windows 的"虚拟转发 DLL"，它们并不是真实文件（在磁盘上的 System32 中可能有也可能没有），
实际功能由 `ntdll.dll` / `kernelbase.dll` 实现。处理规则：

- 若该 API Set 属于 Win10+ 内置 → 分类为 OsCore，仅在 target ≤ Win8.1 时警告
- 若来自 UCRT → 分类为 Redistributable
- 不将其加入"待复制"列表，而是通过捆绑 UCRT Redist 解决

### 5.5 核心数据结构

```cpp
// engine/dep_result.h

enum class DllCategory {
    OsCore,          // Windows OS 核心，永远存在
    Redist,          // 可再发行运行时（VC++/UCRT/DirectX）
    ThirdParty,      // 第三方库
    ApiSet,          // api-ms-win-* 虚拟转发 DLL
    Unknown,         // 未分类
};

enum class DepStatus {
    Found,           // 已在搜索路径中找到（ThirdParty/Redist）
    SystemPresent,   // OsCore，目标机器必然存在，跳过
    MaybeAbsent,     // Redist/ApiSet，当前机器有但目标机可能没有
    Missing,         // 在所有路径中均未找到
    UserExcluded,    // 用户手动排除
};

struct DepNode {
    std::string      name;            // DLL 文件名（小写）
    std::string      resolved_path;   // 找到时的完整路径（空=未找到）
    DllCategory      category;
    DepStatus        status;
    std::string      redist_package;  // Redist 时标注来源，如 "VC++ 2022 x64"
    bool             need_deploy;     // 是否需要复制到发布目录
    std::vector<std::shared_ptr<DepNode>> children;
};

struct RedistRequirement {
    std::string name;          // "Visual C++ 2022 Redistributable (x64)"
    std::string url;           // 微软官方下载链接
    std::string installer_var; // NSIS 中嵌入安装包变量名（可选）
};

struct DepReport {
    std::string                          target_exe;
    std::shared_ptr<DepNode>             root;
    std::vector<DepNode*>                missing;          // 完全找不到
    std::vector<DepNode*>                maybe_absent;     // 可能在目标机缺失
    std::vector<DepNode*>                to_copy;          // 需要复制
    std::vector<RedistRequirement>       redist_needed;    // 需要的 Redist 包
};
```

## 六、PE 解析方案

### 6.1 手写轻量解析器（推荐，无额外依赖）

```cpp
// engine/pe_parser.h
class PEParser {
public:
    // 返回该 PE 文件直接导入的 DLL 名列表（不递归）
    static std::vector<std::string> GetImports(const std::string& path);

private:
    static bool ReadDosHeader(std::ifstream& f, DWORD& peOffset);
    static bool ReadImportTable(std::ifstream& f, DWORD peOffset,
                                std::vector<std::string>& out);
};
```

实现步骤：
1. 读取 MZ 头，定位 PE 签名偏移
2. 读取 IMAGE_NT_HEADERS，获取 IMAGE_OPTIONAL_HEADER.DataDirectory[1]（导入目录）
3. 遍历 IMAGE_IMPORT_DESCRIPTOR，读取每项的 `Name` RVA → 转换为文件偏移 → 读取 DLL 名字符串

### 6.2 使用 LIEF（功能完整，支持 ARM/x64/混淆 PE）

```cpp
auto binary = LIEF::PE::Parser::parse(path);
for (auto& imp : binary->imports()) {
    dlls.push_back(imp.name());
}
```

## 七、依赖解析流程

### 7.1 分类数据库（内置，代码中以静态表维护）

```cpp
// engine/dll_classifier.h
class DllClassifier {
public:
    // 初始化时加载内置白名单 + 用户自定义规则
    void Load(const std::string& config_path);

    struct ClassifyResult {
        DllCategory  category;
        std::string  redist_package; // Redist 时填写，如 "VC++ 2022 x64"
        bool         need_deploy;    // OsCore=false，其余=true
    };

    ClassifyResult Classify(const std::string& dll_name_lower,
                            TargetOsVersion    target_os) const;

private:
    // OsCore 白名单：kernel32.dll, ntdll.dll, ...
    std::unordered_set<std::string> os_core_;

    // Redist 规则：前缀匹配 -> RedistInfo
    // vcruntime140 -> {VC++ 2022, need_deploy=true}
    // ucrtbase    -> {UCRT, need_deploy=(target<Win10)}
    // api-ms-win-crt -> {UCRT, need_deploy=(target<Win10)}
    struct RedistRule { std::string prefix; std::string package; bool always_deploy; };
    std::vector<RedistRule> redist_rules_;
};
```

### 7.2 解析算法

```
输入: target_exe, search_paths, target_os_version

DepResolver::Resolve():
    visited  = {}                  // dll_name -> DepNode*
    queue    = [target_exe]
    redists  = set()               // 收集需要的 Redist 包名

    while queue not empty:
        current_file = queue.pop()
        imports = PEParser::GetImports(current_file)

        for dll_name in imports (lower-cased):
            if dll_name in visited: continue

            cr = classifier.Classify(dll_name, target_os)

            node.category = cr.category
            node.need_deploy = cr.need_deploy

            if cr.category == ApiSet:
                // api-ms-win-* 虚拟 DLL，不递归，仅记录
                node.status = SystemPresent or MaybeAbsent
                if cr.need_deploy: redists.insert(cr.redist_package)

            elif cr.category == OsCore:
                node.status = SystemPresent
                node.need_deploy = false

            else:  // ThirdParty or Redist
                resolved = SearchInPaths(dll_name, search_paths)
                if resolved:
                    node.resolved_path = resolved
                    node.status = Found
                    if cr.need_deploy: queue.push(resolved)   // 递归
                else:
                    node.status = Missing
                if cr.category == Redist and cr.need_deploy:
                    redists.insert(cr.redist_package)
                    node.status = MaybeAbsent   // 本机有但目标机可能没有

            visited[dll_name] = node

    report.redist_needed = BuildRedistList(redists)
    return report
```

### 7.3 搜索路径优先级（可配置）

1. 目标 exe 所在目录
2. 用户自定义路径列表（按顺序）
3. 系统 PATH（可选开关，默认关闭避免混入开发机特有路径）
4. Windows System32 / SysWOW64（仅用于确认文件存在，不作为复制来源）

> 第 4 条特别说明：System32 中找到的文件若属于 **Redist** 类，仍标记为 `MaybeAbsent`，
> 因为它可能是开发机安装 VC++ Redist 后才有的，目标机未必存在。

### 9.2 NSIS 脚本生成

```cpp
// engine/installer_gen.h
class InstallerGen {
public:
    struct RedistEntry {
        std::string name;           // "VC++ 2022 x64"
        std::string installer_path; // 捆绑的 vc_redist.x64.exe 路径（可空）
        std::string check_reg_key;  // 安装检测注册表键，已装则跳过
        std::string silent_args;    // 静默安装参数，如 "/install /quiet /norestart"
    };

    struct Config {
        std::string app_name;
        std::string app_version;
        std::string exe_name;
        std::string install_dir_default;
        std::vector<std::string>  app_files;    // 主程序 + 所有 ThirdParty DLL
        std::vector<RedistEntry>  redists;      // 需要捆绑的 Redist 安装包
        bool        bundle_redist;              // true=捆绑进安装包；false=仅生成下载提示
        std::string output_installer;
    };

    static bool GenerateScript(const Config& cfg, const std::string& nsi_path);
    static bool Compile(const std::string& nsi_path,
                        const std::string& makensis_path);
};
```

生成的 NSIS 脚本模板（含 Redist 前置检查）：

```nsis
!define APP_NAME    "${app_name}"
!define APP_VERSION "${version}"
OutFile "${output_installer}"
InstallDir "$PROGRAMFILES\${APP_NAME}"
RequestExecutionLevel admin   ; Redist 安装需要管理员权限

; ── 主安装 ──────────────────────────────────────────────
Section "Main Application" SEC_MAIN
  SetOutPath "$INSTDIR"
  ; 逐文件生成（仅 ThirdParty + 明确需要的 Redist DLL）
  File "${app_file_1}"
  File "${app_file_2}"
  ; ...
  CreateShortcut "$DESKTOP\${APP_NAME}.lnk" "$INSTDIR\${exe_name}"
  WriteUninstaller "$INSTDIR\Uninstall.exe"
SectionEnd

; ── VC++ 运行时（如分析结果包含 vcruntime140.dll）────────
Section "Visual C++ 2022 Redistributable" SEC_VCREDIST
  ; 检测是否已安装（跳过重复安装）
  ReadRegStr $0 HKLM \
    "SOFTWARE\Microsoft\VisualStudio\14.0\VC\Runtimes\X64" "Installed"
  StrCmp $0 "1" vcredist_done

  SetOutPath "$TEMP"
  File "${vc_redist_x64_exe}"          ; 捆绑进安装包
  ExecWait '"$TEMP\vc_redist.x64.exe" /install /quiet /norestart'
  Delete "$TEMP\vc_redist.x64.exe"

  vcredist_done:
SectionEnd

; ── UCRT（目标为 Win7/8.1 时生成此段）──────────────────
Section "Universal CRT" SEC_UCRT
  ReadRegStr $0 HKLM \
    "SOFTWARE\Microsoft\Windows\CurrentVersion\Component Based Servicing\Packages\Microsoft-Windows-UCRT*" ""
  StrCmp $0 "" 0 ucrt_done

  SetOutPath "$TEMP"
  File "${windows8.1-kb2999226-x64.msu}"
  ExecWait 'wusa.exe "$TEMP\windows8.1-kb2999226-x64.msu" /quiet /norestart'
  Delete "$TEMP\windows8.1-kb2999226-x64.msu"

  ucrt_done:
SectionEnd

; ── 卸载 ────────────────────────────────────────────────
Section "Uninstall"
  Delete "$INSTDIR\*.*"
  RMDir  "$INSTDIR"
  Delete "$DESKTOP\${APP_NAME}.lnk"
SectionEnd
```

> **不捆绑模式**（`bundle_redist=false`）：生成的脚本改为在安装完成后弹出提示框，
> 列出需要手动下载安装的 Redist 包及其官方链接。适合安装包体积敏感的场景。

| 库 | 获取方式 |
|----|----------|
| wxWidgets 3.2 | https://github.com/wxWidgets/wxWidgets/releases — 下载源码，CMake 编译 |
| LIEF (可选) | `vcpkg install lief` 或 CMake FetchContent |
| minizip-ng | `vcpkg install minizip-ng` 或 CMake FetchContent |
| nlohmann/json | 单头文件，直接下载 `json.hpp` 放入 third_party/ |
| NSIS | https://nsis.sourceforge.io — 安装到本地，运行时调用 makensis.exe |

## 十二、构建配置（CMakeLists.txt 骨架）

```cmake
cmake_minimum_required(VERSION 3.20)
project(LibDeploy)
set(CMAKE_CXX_STANDARD 17)

# wxWidgets
find_package(wxWidgets REQUIRED COMPONENTS core base)
include(${wxWidgets_USE_FILE})

# minizip-ng
find_package(minizip CONFIG REQUIRED)

# nlohmann/json
include_directories(third_party)

file(GLOB_RECURSE APP_SOURCES    app/*.cpp)
file(GLOB_RECURSE ENGINE_SOURCES engine/*.cpp)
file(GLOB_RECURSE CONFIG_SOURCES config/*.cpp)

add_executable(LibDeploy WIN32
    ${APP_SOURCES}
    ${ENGINE_SOURCES}
    ${CONFIG_SOURCES}
)

target_link_libraries(LibDeploy
    ${wxWidgets_LIBRARIES}
    minizip::minizip
)
```

## 十三、开发阶段规划

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| P0 引擎基础 | PE 解析 + DllClassifier（OsCore白名单+Redist规则）+ DepResolver | 命令行可验证的分类与解析 |
| P1 UI 骨架 | wxWidgets 主窗口 + 依赖树（四色图标）+ 目标OS选择 | 能展示依赖并区分类别 |
| P2 复制功能 | FileDeployer（ThirdParty+可选Redist）+ 日志 + 搜索路径管理 | 主要工作流跑通 |
| P3 Redist 处理 | Redist 警告面板 + Redist 安装包缓存 + NSIS 捆绑/提示两种模式 | 系统依赖问题完整处理 |
| P4 打包 | ZIP 打包 + NSIS 脚本生成与编译 | 完整部署功能 |
| P5 收尾 | 配置持久化、错误处理、用户自定义分类规则 | 生产可用 |

## 十四、系统依赖覆盖范围说明

### 14.1 已覆盖的系统依赖场景

| 场景 | 处理方式 |
| --- | --- |
| VC++ 2015-2022 运行时（vcruntime140.dll 等） | 标记 Redist，支持复制 DLL 或捆绑 vc_redist.exe |
| VC++ 2013 及更早运行时 | 同上，内置规则表覆盖 |
| Universal CRT（ucrtbase.dll） | Win10+ 标记 OsCore；Win7/8.1 标记 Redist，生成 KB2999226 安装段 |
| api-ms-win-crt-*.dll（UCRT API Set） | 标记 ApiSet，不复制文件，由 UCRT Redist 覆盖 |
| DirectX Shader Compiler（d3dcompiler_4?.dll） | 标记 Redist，需随包复制 |
| Media Foundation（mfplat.dll 等） | 标记 Redist，生成警告（N版系统需安装 Media Feature Pack） |

### 14.2 尚未覆盖的场景

- **运行时动态加载**：`LoadLibrary` / COM 插件不在静态分析范围内，需用户手动添加
- **驱动层依赖**：GPU 驱动 DLL（nvapi.dll 等）不做处理
- **SxS 并行程序集**（老式 VC++ 6/7 manifest）：暂不支持

### 14.3 后续扩展方向

- 支持 Linux ELF（解析 `ldd` 输出或直接读 `.dynamic` 节）
- 支持 macOS Mach-O（`otool -L`）
- Qt 插件目录自动发现（platform/imageformats/sqldrivers）
- 集成 `windeployqt` / `linuxdeployqt` 作为可选后端
