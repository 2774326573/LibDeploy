Place es.exe here to enable full-disk DLL search via Everything.

Download es.exe from:
  https://www.voidtools.com/support/everything/command_line_interface/

Direct download (x64):
  https://www.voidtools.com/es-1.1.0.27.x64.zip

Extract es.exe into this directory, then rebuild LibDeploy.
The build system will automatically copy es.exe to build/bin/ alongside LibDeploy.exe.

Requirements:
  - Everything 1.4+ must be installed and running
  - es.exe version must match Everything version
